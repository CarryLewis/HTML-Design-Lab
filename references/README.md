# References

别人的设计实例。只观察，不把原站当成我们的组件库。

| 目录 | `kind` | ID 前缀 |
| --- | --- | --- |
| [websites/](websites/) | 公开网页 | `ref.web.{slug}` |
| [screenshots/](screenshots/) | 无站点归属的截图 | `ref.ss.{slug}` |
| [github/](github/) | 开源仓库 | `ref.github.{slug}` |
| [design-systems/](design-systems/) | 设计系统文档或代码 | `ref.ds.{slug}` |

每个条目一个 `{slug}/` 文件夹，从 [templates/reference.md](../templates/reference.md) 与 [templates/observation.md](../templates/observation.md) 复制。

必做：`meta.md`、`observation.md`、来源分类 A–F、许可登记。有截图则放 `screenshots/`，禁止只有图没有观察。
