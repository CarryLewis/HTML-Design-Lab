# Design System

已晋升、许可安全、属于我们的系统。当前为空。

本目录 **不是** Reference 的镜像。截图、原站 HTML、品牌资产、未核实的 Estimated 像素都不进入这里。

## 何时可以写入

必须同时满足 [skills/promotion-checklist.md](../skills/promotion-checklist.md)：

- Pattern `transferability: high` 且 `brand_specific: false`
- 已有 Principle
- `information` / `reusability` / `transferability` 均 ≥ 3
- Anti-slop 结论为 keep
- 许可允许改编，或实现完全重写且无品牌资产
- Tokens 已收敛进 [`tokens/`](../tokens/)，不再是原站魔法数
- 用户明确要求晋升或「写入 Design System」

## 目录

| 路径 | 用途 |
| --- | --- |
| [foundations/](foundations/) | 从已晋升 tokens 写出的颜色、字体、间距、形状、动效说明 |
| [components/](components/) | 从 `components/{slug}/` 晋升过来的、可在未来项目使用的抽象 |

实验性重写仍留在 [`components/`](../components/)。未晋升前不要把文件复制到本目录「备用」。
