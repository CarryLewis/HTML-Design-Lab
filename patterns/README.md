# Patterns

抽象的 **What**：可复用的设计范式，不是某个网站的皮肤。

分类由 [catalog/taxonomy.md](../catalog/taxonomy.md) 锁定。一篇 Pattern 一个文件：`{nn-category}/{slug}.md`。

ID：`pat.{category}.{slug}`，例如 `pat.layout.editorial-split-view`。

从 [templates/pattern.md](../templates/pattern.md) 复制。抽取后更新 [catalog/registry.yaml](../catalog/registry.yaml) 与 [catalog/patterns.md](../catalog/patterns.md)。
